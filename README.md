* Stellar Spectral Type Classification - Harvard Scheme

This project implements an automated classification system for stellar spectral types following the **Harvard Classification** scheme. The classification is performed **based on stellar effective temperature**, mapping temperature values to spectral classes and subclasses.

* Project Overview

- **Input:** Stellar effective temperature
- **Output:** Spectral type label according to Harvard classes and subclasses (e.g., G2, K5)
- **Approach:** Uses temperature thresholds and interpolation to assign spectral classes consistent with classical Harvard classification
- **Applications:** Stellar population studies, astrophysical parameter estimation, data labeling for surveys

The main results may be checked in the notebooks folder, mainly on the notebook `4.harvard_class.ipynb`. 

* Background

The Harvard Classification system categorizes stars primarily by their surface temperature, organizing them into spectral classes from hot O-type stars to cool M-type stars. This temperature-based classification remains a fundamental tool in astrophysics.

Key historical contributions include:

- **C. E. Pickering (1890)**, who pioneered spectral classification based on stellar absorption lines.  
- **Annie Jump Cannon (1920s)**, who established the Harvard spectral classification sequence widely used today.

For modern treatments, see:

- Gray, R. O., & Corbally, C. J. (2009). *Stellar Spectral Classification*. Princeton University Press.
